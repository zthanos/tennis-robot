# Archived intake CAD

These models are `HISTORICAL_SUPERSEDED` and are not current manufacturing
geometry. The current physical architecture is fixed-motor direct drive with
ball and tyre compliance; see
[`standalone-intake-fixed-motor-compliant-tyre.md`](../../../docs/mechanism/standalone-intake-fixed-motor-compliant-tyre.md).

- `straight-cheek-aluminium-rail-study/` preserves the pre-Option-A structure
  source, preview, export helper, and generated STLs.
- `standalone-guide-definition/` preserves the rejected translating-pod guide
  allocation.
