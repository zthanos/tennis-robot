# Archive body panels — ΜΗΝ ΤΥΠΩΣΕΙΣ

Τα περιεχόμενα αυτού του φακέλου είναι **superseded** και διατηρούνται μόνο
για ιστορικό/ιχνηλασιμότητα. **ΜΗΝ ΤΥΠΩΣΕΙΣ** STL ή geometry από εδώ.

- `concepts-a-e/`: concepts A–E, οι παλιοί renderers, QA scripts/results και
  εικόνες τους. Αντικαταστάθηκαν από το επιλεγμένο concept F στο P2-86.
- `p284-review/`: παλιές εικόνες review του αρχικού rear-F P2-84.
  Αντικαταστάθηκαν από τα P2-86 renders και τις στιβαρές συνδέσεις.

Ενεργές πηγές: `../body-panels-f.scad`, `../body-panels-f-support.scad` και
`../body-panels-f-rear-v2.scad`.
