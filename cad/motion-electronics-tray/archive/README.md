# Superseded perfboard faceplates

The `perfboard-faceplate.*` family belongs to the older combined IDC-header
layout. The `unified-keyed-faceplate-study.*` and unversioned 2+4 coupon are
the earlier v1 fit study. Their STL/PNG exports are **not** the current
print files.

Use `../unified-keyed-faceplate-v2.stl`, `../unified-keyed-skirt-v2.stl`
and the `../keyed-2plus4-port-fit-coupon-v2.stl` for the Rev C dry-fit.
The active v2 SCAD still includes `../unified-keyed-faceplate-study.scad`;
that parametric source remains in the parent directory deliberately.

The rejected side-entry stand clips and two superseded retainer concepts also
live here. The active front-loaded stand retainer remains in the parent
directory; archival clips are **not** print recommendations.
