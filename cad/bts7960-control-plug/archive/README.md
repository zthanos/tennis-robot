# Superseded BTS7960 plug experiments

These STL and PNG files are historical fit tests and **must not be printed
for the Rev C perfboard**. The current printable set is listed in
[`../README.md`](../README.md).

- `2p-*` and `3p-*` plus `perfboard-end-v0.scad`: discarded 3+2 cable-end
  approach with separate loose board shrouds.
- `plug-*-v0/v1` and `plug-v0/v1.scad`: older soldered-header driver shells.
- `plug-*-v2`, fit images and height coupon: superseded driver-side 3+3
  jumper fit tests. The active v3 source still includes the **unarchived**
  `../plug-v2-jumpers.scad` as a source dependency.
- `perfboard-*-v1`, collars and the v1 README: older cable-tie shells and
  loose collars. The active M3 version still includes the **unarchived**
  `../perfboard-male-end-v1.scad` as a source dependency.
- `README-legacy.md`: earlier project notes, retained for traceability.

The source files kept in the parent directory are not print recommendations;
check the active README before exporting or using an STL.
