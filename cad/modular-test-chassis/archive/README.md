# Archived chassis designs — NOT FOR CURRENT PRINTING

Recoverable historical files. Current geometry: `../modular-chassis-v3.scad`;
current exports: `../stl-v3/` plus the P2-77 MPU mount listed in
`../../ACTIVE-PRINT-SET.md`. **ΜΗΝ ΤΥΠΩΣΕΙΣ** αρχεία από αυτόν τον κατάλογο.

- `packaging-concept/`: early packaging concept and its two images; superseded
  by v2. Relative references in the archived SCAD were adjusted to remain usable.
- `reference-previews/`: older standalone/top/reference previews, not guaranteed
  to match the current front 50×20. Use `../modular-chassis-v2-assembly.png` instead.
- `middle-brace-50x30/`: previous middle crossbar and ramp cradles.
- `stl-v2-front-axis-135mm/`: separate Gamma bodies from the earlier axle layout.
- `v2-chassis/`: superseded v2 export/studies and inactive STL; replaced by
  chassis v3 and P2-78 sockets/side braces. The old source remains at
  `../modular-chassis-v2.scad` only because the motor nut-keeper uses its
  envelopes for QA; it is not an active print release.
- `p277-torsion-node/`: centre node and drill jig replaced by P2-78 side braces.
- `p278-superseded-stl/`: discarded T-clamps/long diagonals and obsolete ballast tab.
- `review-images-p252-p277/`: unreferenced historical review renders only.

The two Gamma STL that remain in `../stl-v2/` are optional visual context
referenced by `modular-chassis-v3.scad`; they are not active print parts.
