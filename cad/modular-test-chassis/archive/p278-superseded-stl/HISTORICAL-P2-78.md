# Superseded by P2-78

These meshes are retained only for traceability and must not be assembled
with the active P2-78 frame:

- `x240_t_clamp.stl`, `x300_t_clamp.stl`
- `torsion_diagonal_half.stl`, `torsion_joiner.stl`
- `torsion_diagonal_onepiece.stl` — rejected: only about 5 mm physical
  ground clearance when installed under the deck

Use the active terminal sockets/sleeves and
2× `../torsion_side_brace.stl` instead.
